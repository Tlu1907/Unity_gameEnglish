# Earth Defender: Monster Invasion

Đồ án môn Học máy & Phát triển Ứng dụng Game bằng Unity.

## Mô tả
Turn-based Grid Puzzle kết hợp Giáo dục Tiếng Anh & AI. Người chơi thu thập
Đạn Tri Thức qua các Ô Vật Phẩm (trả lời quiz tiếng Anh do AI sinh động) để
tiêu diệt quái vật và giải phóng bản đồ.

## Yêu cầu
- Unity 6 (LTS)
- .NET / C#
- OpenAI API Key (đặt trong biến môi trường hoặc file config KHÔNG commit lên Git)

## Cách chạy
1. Mở project bằng Unity Hub.
2. Mở scene `Assets/_Project/Scenes/MainMenu.unity`.
3. Nhấn Play.

## Tài liệu
Xem `QUY_TRINH_PHAT_TRIEN.md` để biết quy trình làm việc, cấu trúc thư mục,
và coding convention của dự án.
