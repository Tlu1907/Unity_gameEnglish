Rows are facing directions in exact order top to bottom: down (front), left, right, up (back). Same species same size and proportions across its four rows. Orthographic RPG top-down three-quarter view, crisp pixel clusters, dark navy outlines, limited color palette with 3 shades per material, attractive polished handheld RPG art; not blurry, not painted, not 3D render. Each monster should read clearly at 48x48 pixels. Symmetric cell centers, feet baseline consistent within each row. Canvas 768x1024 or equivalent 3:4 ratio. Transparent background everywhere outside the monsters.
